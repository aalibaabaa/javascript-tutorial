# JavaScript Tutorial

Willkommen zum JavaScript-Tutorial! Dieses Repository enthält 16 Lektionen, die dich Schritt für Schritt in die Welt von JavaScript einführen – von den Grundlagen bis hin zu modernen ES6+-Features und einem abschließenden Projekt.

## Voraussetzungen

- Windows 11
- Visual Studio Code (VSCode)
- Ein moderner Webbrowser (z. B. Google Chrome)

> Siehe [docs/setup-windows11-vscode.md](docs/setup-windows11-vscode.md) für die detaillierte Einrichtungsanleitung.

## Struktur

```
javascript-tutorial/
├── README.md
├── docs/
│   ├── setup-windows11-vscode.md
│   └── teaching-guidelines-ass.md
└── lessons/
    ├── lesson-01/   # Einführung & Einrichtung
    ├── lesson-02/   # Variablen & Datentypen
    ├── lesson-03/   # Operatoren
    ├── lesson-04/   # Strings
    ├── lesson-05/   # Arrays
    ├── lesson-06/   # Objekte
    ├── lesson-07/   # Kontrollfluss (if/else)
    ├── lesson-08/   # Schleifen
    ├── lesson-09/   # Funktionen
    ├── lesson-10/   # DOM-Manipulation
    ├── lesson-11/   # Events
    ├── lesson-12/   # Formulare
    ├── lesson-13/   # Fetch & APIs
    ├── lesson-14/   # ES6+ Features
    ├── lesson-15/   # Styling & CSS-Integration
    └── lesson-16/   # Abschlussprojekt
```

Jede Lektion enthält:

| Datei/Ordner | Inhalt |
|---|---|
| `lesson.md` | Theorie und Erklärungen |
| `exercises.md` | Übungsaufgaben |
| `starter/` | Startcode für die Übungen |
| `solution/` | Musterlösung |

## Pfade

Alle Lektionen befinden sich unter:

```
C:\Projekte\javascript-tutorial\lesson-XX\
```

## Zeitplan

Jede Lektion ist auf **90 Minuten** ausgelegt:

- ⏱ 0–20 Min: Theorie & Erklärung
- ⏱ 20–60 Min: Übungen (Starter-Code)
- ⏱ 60–80 Min: Besprechung & Musterlösung
- ⏱ 80–90 Min: Fragen & Ausblick
