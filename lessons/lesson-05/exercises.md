# Übungen – Lektion 05: Arrays

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-05\`

Öffne `starter/index.html` in VSCode und bearbeite `starter/script.js`.

---

## Aufgabe 1: Array erstellen

- [ ] Erstelle ein Array `lieblingsfarben` mit mindestens 4 Farben.
- [ ] Gib die erste und letzte Farbe aus.
- [ ] Gib die Anzahl der Elemente aus.

---

## Aufgabe 2: Elemente hinzufügen und entfernen

- [ ] Füge eine neue Farbe am Ende hinzu (`push`).
- [ ] Entferne die letzte Farbe (`pop`).
- [ ] Füge eine Farbe am Anfang hinzu (`unshift`).
- [ ] Gib das Array nach jedem Schritt aus.

---

## Aufgabe 3: Suchen im Array

Gegeben: `let staedte = ["Berlin", "Hamburg", "München", "Köln", "Frankfurt"];`

- [ ] Prüfe, ob `"München"` enthalten ist.
- [ ] Finde den Index von `"Hamburg"`.
- [ ] Extrahiere die ersten 3 Städte mit `slice`.

---

## Aufgabe 4: Array sortieren

- [ ] Erstelle ein Array mit 6 zufälligen Zahlen.
- [ ] Sortiere das Array aufsteigend.
- [ ] Gib das sortierte Array aus.

---

## Aufgabe 5: Einkaufsliste (Bonus)

- [ ] Erstelle eine leere Einkaufsliste als Array.
- [ ] Füge 5 Produkte mit `push` hinzu.
- [ ] Gib alle Produkte mit `forEach` aus.
- [ ] Entferne das erste Produkt mit `shift`.

---

## Selbstüberprüfung

- [ ] Beginnt die Indizierung bei 0?
- [ ] Funktionieren alle Array-Methoden korrekt?
