# Übungen – Lektion 04: Strings

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-04\`

Öffne `starter/index.html` in VSCode und bearbeite `starter/script.js`.

---

## Aufgabe 1: String-Grundlagen

- [ ] Erstelle eine Variable `begruessung` mit dem Wert `"Hallo, JavaScript!"`.
- [ ] Gib die Länge des Strings aus.
- [ ] Gib den String in Großbuchstaben aus.
- [ ] Gib den String in Kleinbuchstaben aus.

---

## Aufgabe 2: Template Literals

- [ ] Erstelle Variablen für `vorname`, `alter` und `hobbys`.
- [ ] Erstelle mit Template Literals einen Satz: `"Ich heiße [Name], bin [Alter] und mag [Hobby]."`

---

## Aufgabe 3: String-Methoden

Gegeben: `let satz = "Der schnelle braune Fuchs springt.";`

- [ ] Prüfe, ob `satz` das Wort `"Fuchs"` enthält.
- [ ] Finde die Position von `"braune"`.
- [ ] Extrahiere das Wort `"Fuchs"` mit `slice`.
- [ ] Ersetze `"Fuchs"` durch `"Hund"`.

---

## Aufgabe 4: Namen verarbeiten

- [ ] Erstelle eine Variable `vollname = "  anna müller  "`.
- [ ] Entferne die Leerzeichen mit `trim()`.
- [ ] Mache den ersten Buchstaben groß (Tipp: `charAt(0).toUpperCase() + ...`).

---

## Aufgabe 5: Satz aufteilen (Bonus)

- [ ] Erstelle `let einkaufsliste = "Äpfel,Bananen,Milch,Brot"`.
- [ ] Teile den String mit `split(",")` in ein Array auf.
- [ ] Gib jedes Element auf einer neuen Zeile aus.

---
