# Übungen – Lektion 13: Fetch & APIs

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-13\`

Öffne `starter/index.html` in VSCode, starte Live Server und bearbeite `starter/script.js`.

> **Hinweis:** Für diese Übungen benötigst du eine Internetverbindung.  
> API-URL: `https://jsonplaceholder.typicode.com`

---

## Aufgabe 1: Ersten Benutzer laden

- [ ] Lade die Daten von `https://jsonplaceholder.typicode.com/users/1`.
- [ ] Zeige Name und E-Mail des Benutzers in der Konsole an.

---

## Aufgabe 2: Daten im DOM anzeigen

- [ ] Lade alle Posts von `https://jsonplaceholder.typicode.com/posts`.
- [ ] Zeige die ersten 5 Titel in der Liste mit der ID `"post-liste"` an.

---

## Aufgabe 3: Fehlerbehandlung

- [ ] Versuche, eine nicht existierende URL aufzurufen.
- [ ] Fange den Fehler mit `try/catch` ab.
- [ ] Zeige eine Fehlermeldung im Element `"fehler"` an.

---

## Aufgabe 4: Ladeindikator

- [ ] Zeige das Element `"laden"` an, bevor die Daten geladen werden.
- [ ] Verstecke es, wenn die Daten geladen wurden.

---

## Aufgabe 5: Benutzer-Suche (Bonus)

- [ ] Lade alle Benutzer von `/users`.
- [ ] Erstelle für jeden Benutzer eine Karte mit Name und E-Mail im Element `"benutzer-liste"`.

---

## Selbstüberprüfung

- [ ] Werden die Daten korrekt angezeigt?
- [ ] Werden Fehler abgefangen?
