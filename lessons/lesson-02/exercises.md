# Übungen – Lektion 02: Variablen & Datentypen

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-02\`

Öffne `starter/index.html` in VSCode und bearbeite `starter/script.js`.

---

## Aufgabe 1: Variablen deklarieren

- [ ] Erstelle eine Variable `vorname` mit deinem Vornamen.
- [ ] Erstelle eine Variable `alter` mit deinem Alter.
- [ ] Erstelle eine Konstante `geburtsstadt` mit deiner Geburtsstadt.
- [ ] Gib alle drei Variablen in der Konsole aus.

---

## Aufgabe 2: Datentypen

- [ ] Erstelle für jeden der folgenden Typen ein Beispiel: `string`, `number`, `boolean`.
- [ ] Prüfe den Typ mit `typeof` und gib das Ergebnis aus.

---

## Aufgabe 3: Variablen verändern

- [ ] Erstelle eine Variable `punkte` mit dem Wert `0`.
- [ ] Erhöhe `punkte` auf `10`.
- [ ] Gib `punkte` aus. Erwartet: `10`.
- [ ] Erhöhe `punkte` um weitere `5`.
- [ ] Gib `punkte` erneut aus. Erwartet: `15`.

---

## Aufgabe 4: const vs. let

- [ ] Erstelle eine Konstante `PI` mit dem Wert `3.14159`.
- [ ] Versuche, `PI` einen neuen Wert zuzuweisen. Was passiert in der Konsole?
- [ ] Erkläre im Kommentar, warum `const` diesen Fehler erzeugt.

---

## Aufgabe 5: Selbstbeschreibung (Bonus)

- [ ] Erstelle Variablen für mindestens 5 Eigenschaften von dir (Name, Alter, Hobbys als String, etc.).
- [ ] Gib einen Satz in der Konsole aus, der all diese Variablen kombiniert.

**Beispiel:**
```
Ich heiße Anna, bin 17 Jahre alt und lebe in Berlin.
```
