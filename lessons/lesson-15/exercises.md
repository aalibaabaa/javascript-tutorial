- [ ] Wähle das Element mit der ID `"farb-box"` aus.

## Aufgabe 2: Klassen umschalten

- [ ] Füge dem Button `"toggle-button"` einen Klick-Listener hinzu.
- [ ] Beim Klick soll die Klasse `"hervorgehoben"` auf `"ziel-element"` umgeschaltet werden.

## Aufgabe 3: Dark Mode

- [ ] Füge dem Button `"dark-mode-btn"` einen Klick-Listener hinzu.
- [ ] Beim Klick soll `"dark-mode"` auf dem `<body>` umgeschaltet werden.
- [ ] Ändere den Button-Text entsprechend.

## Aufgabe 4: CSS-Variablen

- [ ] Ändere die CSS-Variable `--hauptfarbe` per JavaScript auf eine neue Farbe.
- [ ] Füge einem Button einen Listener hinzu, der bei jedem Klick zwischen zwei Farben wechselt.

## Aufgabe 5: Farbpalette (Bonus)
