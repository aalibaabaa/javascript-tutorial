# Übungen – Lektion 11: Events

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-11\`

Öffne `starter/index.html` in VSCode, starte Live Server und bearbeite `starter/script.js`.

---

## Aufgabe 1: Klick-Event

- [ ] Füge dem Button mit der ID `"klick-button"` einen Click-Event-Listener hinzu.
- [ ] Beim Klick soll der Text im Element `"ausgabe"` auf `"Button wurde geklickt!"` geändert werden.

---

## Aufgabe 2: Klickzähler

- [ ] Erstelle eine Variable `zaehler = 0`.
- [ ] Beim Klick auf `"zaehler-button"` soll `zaehler` erhöht werden.
- [ ] Zeige den aktuellen Wert in `"zaehler-ausgabe"` an.

---

## Aufgabe 3: Maus-Hover-Effekt

- [ ] Füge dem Element `"hover-box"` Event-Listener für `mouseover` und `mouseout` hinzu.
- [ ] Bei `mouseover`: Hintergrundfarbe auf `"orange"` setzen.
- [ ] Bei `mouseout`: Hintergrundfarbe zurücksetzen.

---

## Aufgabe 4: Tastatur-Event

- [ ] Füge dem gesamten Dokument einen `keydown`-Event-Listener hinzu.
- [ ] Gib die gedrückte Taste in der Konsole aus.
- [ ] Zeige die gedrückte Taste auch im Element `"taste-ausgabe"` an.

---

## Aufgabe 5: Farb-Wechsler (Bonus)

- [ ] Erstelle 3 Buttons für die Farben Rot, Grün, Blau.
- [ ] Beim Klick auf einen Button soll der Hintergrund der gesamten Seite die entsprechende Farbe bekommen.

---

## Selbstüberprüfung

- [ ] Reagieren alle Buttons auf Klicks?
- [ ] Gibt es Fehler in der Konsole?
