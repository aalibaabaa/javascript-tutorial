# Übungen – Lektion 16: Abschlussprojekt

**Pfad:** `C:\Projekte\javascript-tutorial\lesson-16\`

Öffne `starter/index.html` in VSCode, starte Live Server und bearbeite `starter/script.js`.

---

## Projektauftrag: To-Do-App

Erstelle eine vollständige Aufgabenverwaltung mit folgenden Features:

---

## Schritt 1: Aufgabe hinzufügen

- [ ] Wenn der Benutzer auf „Hinzufügen" klickt (oder Enter drückt), soll eine neue Aufgabe erstellt werden.
- [ ] Leere Eingaben sollen ignoriert werden.
- [ ] Das Eingabefeld soll nach dem Hinzufügen geleert werden.

---

## Schritt 2: Aufgaben anzeigen

- [ ] Alle Aufgaben sollen in der Liste `"aufgaben-liste"` angezeigt werden.
- [ ] Jede Aufgabe besteht aus: Text, „Erledigt"-Checkbox und „Löschen"-Button.

---

## Schritt 3: Aufgabe als erledigt markieren

- [ ] Wenn der Benutzer auf die Checkbox klickt, soll die Aufgabe als erledigt markiert werden.
- [ ] Erledigte Aufgaben sollen visuell durchgestrichen dargestellt werden.

---

## Schritt 4: Aufgabe löschen

- [ ] Wenn der Benutzer auf „Löschen" klickt, soll die Aufgabe entfernt werden.
- [ ] Die Liste soll anschließend aktualisiert werden.

---

## Schritt 5: Filterung

- [ ] Erstelle drei Buttons: „Alle", „Offen", „Erledigt".
- [ ] Die Ansicht soll entsprechend gefiltert werden.

---

## Schritt 6: Persistenz mit localStorage

- [ ] Speichere die Aufgabenliste nach jeder Änderung im `localStorage`.
- [ ] Lade die Aufgaben beim Start der App aus dem `localStorage`.

---

## Bonusaufgaben

- [ ] Zeige die Anzahl der offenen Aufgaben an.
- [ ] Füge eine „Alle löschen"-Funktion hinzu.
- [ ] Füge einen Dark Mode hinzu.

---

## Selbstüberprüfung

- [ ] Werden Aufgaben nach einem Neuladen der Seite noch angezeigt?
- [ ] Funktioniert die Filterung korrekt?
- [ ] Gibt es keine Fehler in der Konsole?
